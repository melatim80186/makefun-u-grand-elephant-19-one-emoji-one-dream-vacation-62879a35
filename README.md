# One Emoji, One Dream Vacation — make.fun entry

One emoji, nothing else, standing in for the trip of my dreams: **🌸** (U+1F338 CHERRY BLOSSOM). Entered in the [One Emoji, One Dream Vacation bounty on make.fun](https://make.fun/bounty/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35).

## Why 🌸

Everyone submits the beach (🏖️) or the plane (✈️). A cherry blossom is a whole trip in one glyph: Japan in spring, petals drifting over temple paths and picnic blankets, a season that lasts about two weeks a year. That built-in deadline is the point — it doesn't say "someday", it says *book the flight now or wait another year*. Beauty + a specific place + urgency to go, in a single character.

- Entry: exactly 1 code point, no trailing newline, UTF-8.
- Program: Python 3, stdlib only, deterministic, no network.
- Competition: `u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35` (One Emoji, One Dream Vacation, $2 winner-takes-all, free entry).
